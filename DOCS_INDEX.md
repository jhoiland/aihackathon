## 🚀 Quick Reference

### Installation
```bash
# Option 1: Automated (Windows)
setup.bat

# Option 2: Automated (Mac/Linux)
chmod +x setup.sh && ./setup.sh

# Option 3: Manual (any OS)
npm install
npm run dev
```

### Access App
```
http://localhost:3000
```

### Build for Production
```bash
npm run build
npm start
```
